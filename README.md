# Đi Đức, đừng đi mù

Sổ tay nghiên cứu Ausbildung điều dưỡng bằng tiếng Việt và tiếng Đức.

Website tĩnh với hai nút hình cờ, bộ lọc chủ đề, nguồn đối chiếu, lộ trình chuẩn bị và ghi chú lưu trong trình duyệt. Ghi chú không đồng bộ giữa thiết bị; có thể xuất thành tệp văn bản.

Nội dung là tư liệu ban đầu, chưa phải bản thảo sách hoàn thiện. Chủ đề cần phỏng vấn được ghi riêng. Nguồn không tự động cập nhật.

## Xuất bản

GitHub Pages: nhánh `main`, thư mục `/ (root)`. Không cần bước build.

Mở `index.html` qua một máy chủ HTTP để xem thử. Các tài sản cờ SVG nằm trong repo; phông chữ dùng Google Fonts với phông dự phòng hệ thống.
